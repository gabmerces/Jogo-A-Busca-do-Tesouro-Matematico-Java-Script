# 🏴‍☠️ Caça ao Tesouro Matemático — Retro Game

Uma aventura interativa em formato de caça ao tesouro desenvolvida para a web, combinando a estética nostálgica dos jogos pixelados antigos com desafios lógicos e matemáticos avançados. 

O projeto foi construído de forma totalmente nativa para aplicar conceitos de desenvolvimento front-end e estruturação de lógica de programação.

---

## 🕹️ O Jogo e Suas Fases

O jogo é dividido em 3 fases progressivas, onde o jogador precisa resolver problemas matemáticos para avançar na jornada e encontrar o tesouro:

*   **Fase 1: Álgebra Fundamental** — Desafios envolvendo equações e funções de 1º e 2º grau.
*   **Fase 2: Lógica e Estruturas** — Problemas focados em Tabela Verdade e Teoria dos Conjuntos.
*   **Fase 3: Matemática Avançada** — Desafios complexos de Logaritmos e Matrizes.

## 🛠️ Tecnologias Utilizadas

O desenvolvimento foi feito utilizando tecnologias web nativas (sem a necessidade de frameworks externos), demonstrando domínio na manipulação do ecossistema front-end básico:

*   **HTML5:** Estruturação semântica das fases, modais e elementos do jogo.
*   **CSS3:** Estilização visual completa, aplicando fontes pixeladas, layout responsivo e efeitos de luz/glow estáticos para manter a atmosfera retrô.
*   **JavaScript (ES6+):** Motor do jogo, controle de fluxo das fases, validação das respostas matemáticas e manipulação dinâmica do DOM.
*   **Protocolo HTTPS:** Garantindo a segurança e integridade na entrega dos recursos web.
